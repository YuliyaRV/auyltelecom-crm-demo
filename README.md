# AuylTelecom CRM — демо

Кликабельный прототип CRM для обработки заявок и подключений интернет-провайдера в сельских населённых пунктах (СНП): единое окно оператора, воронка подключений, карточка клиента и управленческая аналитика.

Построен по техническому заданию: дедупликация лидов по телефону/ИИН, фиксированный справочник причин отказа, SLA по каналам, отдельный подэтап «Выезд/монтаж», ролевая матрица прав (Контакт-центр / Хантер / Агент / Регпредставитель / Руководитель), автораспределение заявок по СНП с эскалацией, и аналитика: цикл сделки по этапам, конверсия «канал × СНП», причины отказа, CPL по каналам.

**Демо-версия:** [https://yuliyarv.github.io/auyltelecom-crm-demo/](https://yuliyarv.github.io/auyltelecom-crm-demo/)

## О данных

Никаких предзаполненных данных в этой версии нет — ни реальных, ни демонстрационных. Приложение открывается с пустыми списками заявок, хантеров и рекламных бюджетов.

Эта статическая версия не имеет бэкенда: всё, что вы вводите через интерфейс (новые обращения, изменения карточек и т.д.), сохраняется только в `localStorage` вашего браузера и никуда не отправляется и ни с кем не синхронизируется. Кнопка «Очистить все данные» в боковой панели стирает локально сохранённое.

## Технические примечания

- Один файл `index.html`, без сборки и зависимостей (кроме шрифтов Google Fonts).
- Интеграции с WhatsApp/Instagram/TikTok, очередь сообщений и WebSocket-инбокс из ТЗ здесь не реализованы — для них нужен реальный бэкенд.
